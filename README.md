# Saucedemo Playwright Automation

This repository contains an **User Product Purchase Flow** for the [Saucedemo](https://www.saucedemo.com/) public demo site using **Playwright with JavaScript**.  

The test scenario covers:  
1. Login with valid credentials  
2. Add a product to the cart  
3. Verify the product in the cart  
4. Logout
